Calculator Payment - Gophers Task 1 (Beginner Project) 🚀

A simple command-line interface (CLI) payment calculator built with Go (Golang). This project was created by a beginner as part of the Gophers assignment to demonstrate a basic understanding of Go syntax, functions, and packages.

✨ Features
* Beginner-Friendly Code: Clean and simple logic for easy learning.
* Calculate Change: Automatically calculates the change for a transaction.
* Input Validation: Notifies the user if the payment is insufficient.
* Colored Output: Uses the fatih/color library to distinguish between successful (green) and failed (red) transactions.

🛠️ Built With
* [Go](https://go.dev/) - The programming language used.
* [Color](https://github.com/fatih/color) - To make the terminal output more interactive.

🚀 How to Run
1. Make sure you have Go installed on your machine.
2. Clone this repository: git clone [https://github.com/ameliaazzahra0204-byte/gophers_1.git](https://github.com/ameliaazzahra0204-byte/gophers_1.git)
